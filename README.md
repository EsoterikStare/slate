# Wall Cards

Custom Home Assistant dashboard cards for a portrait, wall-mounted kiosk:
a week-row calendar anchored to the bottom of the screen, clock, date and
weather at the top, and a rotating photo background in between.

Work in progress — see [PLANNING.md](PLANNING.md) for the design.

## Development

```bash
pnpm install
pnpm test        # unit tests
pnpm storybook   # component gallery
pnpm build       # dist/wall-cards.js
```
